# LauncherMP 다운로드

런처 실행 파일과 변경사항을 배포하는 저장소입니다.

- [최신 정식 버전 다운로드](https://github.com/inseo0o/kart_revive-release/releases/latest)
- [전체 버전 및 시험판](https://github.com/inseo0o/kart_revive-release/releases)

받은 `LauncherMP_N.exe`를 게임 폴더 `C:\Kart2`에 넣고 실행하세요. 같은 방의 모든 참가자와 관전자는 같은 실행 파일을 사용해야 합니다.

시험판은 실제 플레이 검증 중인 버전입니다. 릴리스 설명에 적힌 시험 범위와 확인사항을 읽어 주세요.

게임 클라이언트와 게임 데이터는 포함하지 않습니다.
